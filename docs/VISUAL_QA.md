# Визуальная проверка Career Quest

Дата: 23 сентября 2026. Chrome на macOS, локальный сервер на 127.0.0.1:8000. Мобильные размеры проверялись через Responsive Mode Chrome DevTools, не на физическом телефоне.

## Проверенные экраны

| Экран / действие | Проверка |
|---|---|
| Вход сотрудника | Форма, выбор роли и вход, десктоп и мобильный экран |
| Профиль E0001 | Заголовки, кольцо прогресса, метрики, карта навыков, история |
| Объяснение рекомендации | Раскрытие факторов и читаемость текста |
| Прогноз Public Speaking Club | Открытие/закрытие; числа и таблица на десктопе и 390 px |
| Вход HR | Ошибка неверного пароля и успешный вход |
| HR | Мобильный обзор 390 px, десктопная таблица и импорт |
| Импорт, 320 px | Поля и кнопка помещаются; без файла показывается понятное сообщение |
| Консоль Chrome | В просмотренном сценарии только ожидаемый HTTP 403 от теста неверного пароля; ошибок выполнения JavaScript не обнаружено |

## Исправления

- Проценты прогноза больше не переносятся на две строки на ширине 390 px.
- Сетка адаптируется к числу рекомендаций, без зарезервированной пустой третьей колонки.
- Усилен контраст вторичного текста; увеличены мобильные подписи и области нажатия.
- Длинные названия и метаданные карточек могут переноситься, показатели уровней сохраняются вместе.
- Мобильные кнопки карточек занимают всю ширину.
- Для HR отображается собственный заголовок страницы.
- Нейтральные подписи счётчиков не требуют склонения по числу.
- Добавлена кнопка возврата при смене профиля и доступные названия диалогов.
- Диалоги ограничены высотой экрана; фон не прокручивается при открытом окне.
- Заголовки таблиц закреплены внутри прокручиваемого списка.
- Убраны технические названия полей gain/max_level из текста прогноза.

## Границы проверки

Это ручная проверка выбранных сценариев, а не гарантия отсутствия любых дефектов. Safari, Firefox, физические телефоны и экранный диктор не проверялись. Загрузка файлов и изменение навыков покрыты существующими API-тестами; полный повтор этих операций через браузер в этой визуальной сессии не выполнялся. Синтаксис обновлённого JavaScript и `git diff --check` проверены.
