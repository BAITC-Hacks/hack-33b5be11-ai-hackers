# Публичное демо на Render

В репозитории готов `render.yaml` для одного бесплатного Python Web Service.
Это конфигурация публикации, а не подтверждение, что сайт уже опубликован.

Подготовка проверена 23 сентября 2026: все 42 теста проходят, включая переключение HTTPS-cookie. Публичный запуск требует отдельной проверки после развёртывания.

1. Войти в https://dashboard.render.com/ под аккаунтом команды.
2. Создать **New → Blueprint**, подключить репозиторий `BAITC-Hacks/hack-33b5be11-ai-hackers`, ветку `main`.
3. Проверить тариф **Free**, задать `HR_PASSWORD` для жюри и команды, применить Blueprint.
4. Дождаться успешного развёртывания. Скопировать фактический HTTPS-адрес из карточки сервиса; адрес заранее не гарантирован.
5. При необходимости включить живой AI: добавить `OPENAI_API_KEY` в Environment сервиса и перезапустить. Ключ не помещать в Git, README или браузерный код. Без ключа сайт работает с явно обозначенным резервным ответом. AI-запросы используют баланс владельца ключа.
6. Проверить `/api/health`, вход сотрудника, прогноз, вход HR и импорт тестового профиля. Живой AI проверять только после согласования передачи тестовых данных.
7. Заменить локальную ссылку в начале README на проверенный публичный адрес и открыть его с другого устройства.

Для ручного создания Web Service: Python, build `pip install -r requirements-web.txt`, start `python -B server.py`; переменные `BIND_ADDRESS=0.0.0.0`, `COOKIE_SECURE=1`, собственный `HR_PASSWORD`. Порт задаёт хостинг через `PORT`.

## Особенности демо

- Бесплатный сервис засыпает после простоя: первое открытие может быть медленным. Перед защитой открыть сайт заранее.
- Файловое состояние `var/state.json` на бесплатном сервисе непостоянное: импорт и симуляции могут сброситься при перезапуске или новом deploy. Исходные профили восстановятся из Git. Данные и симуляции общие для посетителей одного экземпляра; для защиты нужен один экземпляр сервера.
- Вход выбором профиля — демонстрационный. Использовать только синтетические профили, не реальные банковские или кадровые данные. Пароль HR передать жюри отдельно.
- Локальный ключ с ноутбука автоматически на хостинг не переносится.

Документация Render: [Web Services](https://render.com/docs/web-services), [Blueprint](https://render.com/docs/blueprint-spec), [ограничения Free](https://render.com/docs/free).
